# गाँव किराना स्टोर (Gaon Kirana Store)

A full-stack MERN (Express/React) application for a local grocery store, featuring product management for owners and easy WhatsApp ordering for customers.

## 🚀 Quick Start

Ensure you have [Node.js](https://nodejs.org/) installed.

1. **Install Dependencies**
   ```bash
   npm run install:all
   ```

2. **Seed Initial Inventory**
   ```bash
   npm run seed
   ```

3. **Start Development Servers (Client & Server)**
   ```bash
   npm run dev
   ```

## 📁 Project Structure

- `server/`: Express.js backend using a JSON file-based database for easy local setup.
- `client/`: Vite-powered React frontend with modern UI.
- `db.json`: Local database file (auto-generated).

## 🔑 Login Info
- **Owner**: Login via the "Owner" tab in the login page.
- **User**: Register/Login via the "User" tab.

## 📱 Features
- Premium Filterable Product Grid.
- Automatic WhatsApp order generation.
- Real-time product management (Price update, Delete, Add) for Owners.
- Responsive design for Mobile & Desktop.
